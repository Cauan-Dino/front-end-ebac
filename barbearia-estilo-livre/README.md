# Barbearia Estilo Livre

Página de uma barbearia fictícia feita com **Bootstrap 5**, como exercício de front-end da EBAC.

## Seções

- **Home**: banner de destaque com botão de chamada para ação
- **Sobre Nós**: proposta da barbearia e números
- **Serviços**: cards do Bootstrap com preço e duração
- **Depoimentos**: componente Carousel
- **Contato**: formulário com nome, e-mail e mensagem, validado com Bootstrap (sem envio real)

## O que foi usado

- Grid System (`container`, `row`, `col-*`, `row-cols-*`) para organizar as seções
- Componentes: Navbar responsiva com menu colapsável, Cards, Carousel, Formulário e Alert
- Classes utilitárias para espaçamento, cores, alinhamento e flexbox
- Bootstrap Icons
- `css/estilos.css` com a paleta da marca (dourado e marrom-escuro)

## Estrutura

```
index.html
css/estilos.css
js/main.js
img/        imagens (SVG) usadas na página
```

## Como abrir

Abra o `index.html` no navegador. O Bootstrap é carregado via CDN.
